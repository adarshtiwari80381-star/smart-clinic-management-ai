# Frontend Pages & Modular Templates

This directory contains modular view templates and page components for the MediFlow AI Clinic Management System:

- `dashboard.html` / Dashboard components
- `patients.html` / Patient registry components
- `doctors.html` / Specialist directory components
- `appointments.html` / Scheduling & conflict calendar components
- `records.html` / Clinical case records
- `aiAssistant.html` / AI triage chat interface

The application utilizes a Single Page Application (SPA) container architecture inside `frontend/index.html` for instant navigation, persistent WebSocket/HTTP session state, and zero-latency switching between clinical views.
